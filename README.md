# thunderbird-rich-text

Thunderbird Rich text editor plugin.

## Features

- Font selection
- Policy
- Text alignment
- Text color
- Text background color
- Highlight
- strikethrough
- Emojis
- List 
- Formatting
- etc ...

## Hard Requirements

- Straight formward packaging and distribution
- Provide advanced text editor 
- Integrate smoothly in the Thunderbird editor

## Brainstorming

The default editor in Thunderbird is very minimal and don't provide user friendly editing options. Goal is to solve this pain point by implementing a rich alternative which provides users and advanced mail editor for their emails
