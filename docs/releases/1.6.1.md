## Compact toolbar branding

- Remove the visible “Rich Text” label from the compose toolbar while keeping
  the existing logo, leaving more room for formatting controls.
- Declare the Thunderbird compatibility range as 128–153.x.
- Add an MIT license to the project.

## Install

Install `thunderbird-rich-text-1.6.1.xpi` through Thunderbird’s Add-ons Manager.
The accompanying `.sha256` file lets you verify the download.
The Experiment API still requires the full-access add-on permission, and all
formatting remains local.

## Verification

All 30 automated tests and the native integration suite pass. Native checks were
run on Thunderbird 153.4.0 ESR on Linux with the English extension interface;
other Thunderbird versions have not been verified.
