Rich Text brings advanced formatting directly to Thunderbird's native message
composer, with a persistent toolbar and floating controls that keep the editor
in place.

## Highlights

- Search all installed font families and enter numeric font sizes in points.
- Choose paragraph styles with previews, line-spacing presets or custom percentages,
  and increase/decrease paragraph spacing.
- Floating panels for fonts, styles, line spacing, emoji, links, and text/background
  colors preserve the message selection without expanding the toolbar.
- Match Thunderbird's active system, light, or dark colors while retaining the
  Rich Text logo.
- Keep native undo/redo, safe links, searchable emoji, and Add-ons Manager settings.
  Thunderbird's original formatting toolbar is hidden by default and can be restored
  from the settings.

## Install

Download `thunderbird-rich-text-1.5.0.xpi` below. In Thunderbird, open **Add-ons and
Themes → gear menu → Install Add-on From File…** and select the XPI. The accompanying
`.sha256` file lets you verify the download.

Native toolbar integration uses a Thunderbird Experiment API and requires the
full-access add-on permission. Formatting stays local; there is no telemetry or
remote code.

## Verification

The manifest declares Thunderbird 128+ compatibility. Native integration was
verified on **Thunderbird 153.4.0 on Linux**; other versions have not been tested.
All 25 automated tests and the native integration suite passed, including
selection preservation, undo/redo, floating panels, live light/dark theme changes,
plain-text safeguards, and cleanup when disabled.
