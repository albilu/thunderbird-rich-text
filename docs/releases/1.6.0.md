## French translations

- Automatically use French when Thunderbird’s interface language is French,
  including regional variants. English remains the fallback for other languages.
- Translate the toolbar, all floating dropdowns, paragraph styles, color names,
  settings, tooltips, accessibility labels, and validation messages.
- Search emoji using French terms such as « fête », « merci » and « travail ».
  Accents are optional; « cœur » and « coeur » both work. English search terms
  remain available.
- Display French decimal labels for line spacing while preserving numeric
  formatting values and Thunderbird’s native undo history.

## Install

Install `thunderbird-rich-text-1.6.0.xpi` through Thunderbird’s Add-ons Manager.
The add-on follows Thunderbird’s interface language; no separate language
setting is needed. The Experiment API still requires the full-access add-on
permission, and all formatting remains local.

The manifest declares Thunderbird 128+ compatibility. Native integration is
tested on Thunderbird 153.4.0 ESR on Linux; other versions have not been verified.

All 30 automated tests pass. Native checks cover English and French interfaces,
formatting, undo/redo, settings, regional French selection, and English fallback.
